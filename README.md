# Dream Form Arena v0.1.7-alpha.1

本轮核心：白蓝飞碟新增 **同调俘获 / 认知改写** 战术链。

## 新能力（白蓝形态，R）

1. 白蓝飞碟升空并减速。
2. 释放蓝白收容光波。
3. 从准星目标或前方视锥中选择一名普通敌方 Bot。
4. 将目标牵引至飞碟并吸入。
5. 短暂进行认知改写。
6. 重新释放，目标成为临时友军 12 秒。
7. 友军自动攻击原敌方，敌方也会反击友军；时间到后恢复敌对。

## 平衡边界

- 同调俘获冷却：14 秒。
- 一次只能处理 1 名 Bot。
- 木桩 Dummy 不可同调。
- 离开白蓝形态、目标死亡/失效会安全中断并恢复目标。
- 捕获过程中白蓝飞碟移动速度大幅降低。
- 现有左键引力锚、E 反制护盾、F 弱点扫描全部保留。
- R 键为上下文能力：绿色=巨大化；白蓝=同调俘获。

## Repository Scope

Dream Form Arena 是一款以“一个英雄拥有多个完全不同可玩身体”为核心规则的第三人称动作冒险游戏。当前仓库以 v0.1.7-alpha.1 可运行垂直原型为主，并保留后续 PvE 冒险、独立 PvP 与多英雄扩展的统一设计入口。

仓库同时包含：

- docs/GDD_v0.1.md：正式游戏设计规格；
- docs/Steam产品愿景与完整化路线_v0.1.md：Steam 产品化方向；
- assets/reference/tao3d-v0.1/：白蓝飞碟、绿色飞碟、火箭炮等 Tao3D 多视图 / 单图重建参考资产；
- tests/test_v017_static.py：v0.1.7 核心机制静态合同检查。

当前产品原则：形态不是“技能换皮”，而是改变移动、战斗、空间使用和探索/事件解法的不同可玩身体。
